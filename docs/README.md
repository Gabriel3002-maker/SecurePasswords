# SecurePasswords Documentation

## Español

SecurePasswords es un gestor de contraseñas local y seguro, pensado para crecer como proyecto de código abierto. En esta versión v1.0.1 se mejora la interfaz, se ordena la estructura del backend y se prepara la documentación para compartir en GitHub Pages.

### Cambios incluidos en v1.0.1
- Mejora inicial de la UI
- Home más claro y menos saturado
- Reorganización básica del backend
- Validación de seguridad para contraseñas más fuertes
- Documentación preparada para GitHub Pages

### Próximos pasos
- Pulir aún más la experiencia visual
- Añadir más módulos de gestión
- Mejorar la documentación técnica y el despliegue

## English

SecurePasswords is a local and secure password manager designed to grow as an open-source project. In this v1.0.1 release, the interface is improved, the backend structure is organized, and the documentation is prepared for GitHub Pages.

### Changes in v1.0.1
- Initial UI improvement
- Cleaner and less crowded home screen
- Basic backend reorganizing
- Stronger password-security validation
- Documentation prepared for GitHub Pages

### Next steps
- Further UI refinement
- Add more management modules
- Improve technical documentation and deployment
